PROfit, сайт о здоровом питании
Учебный проект ОПД ГУАП, группа 4528: Ярошенко А. (капитан), Костин М. (дизайн и разработка), Колычев А. (структура, тексты и данные, записка и паспорт).
Адрес сайта: https://ejik-star.github.io/profit/
Исходники: https://github.com/ejik-star/profit

Что внутри
  index.html        главная: чек замены (листается кнопками, стрелками и свайпом), цифры сайта, оглавление, последняя норма из калькулятора
  calculator.html   калькулятор КБЖУ (формула Миффлина-Сан Жеора, возраст от 16 лет), разбивка расчёта, ИМТ, запоминание данных
  swaps.html        таблица замен: 27 замен, из них 21 бюджетная; поиск, «только бюджетные», группы, сортировка, Б/Ж/У каждой стороны
  tips.html         13 коротких советов-стикеров, отметка «уже пробую», случайный совет
  products.html     КБЖУ 93 продуктов на 100 г: поиск, группы, сортировка по столбцам, тарелка дня
  about.html        о команде, контакт, ссылка на опрос, что сайт хранит в браузере и кнопка «стереть всё»
  404.html          страница «нет такой страницы» (GitHub Pages показывает её сам, ссылки работают на любой глубине адреса)
  css/site.css      все стили одним файлом: дневная и ночная тема, телефон, печать, уменьшенное движение
  js/data.js        продукты, замены и советы (данные USDA FoodData Central, SR Legacy)
  js/main.js        общее: меню, тема, хранилище в браузере, копирование, плавное появление блоков
  js/calc.js, home.js, swaps.js, products.js, tips.js   логика страниц
  img/              логотип, рисунки, картинка для соцсетей og.png, иконка для телефона
  robots.txt, sitemap.xml   для поисковиков
  tests/            автотесты

Сайт сделан на чистых HTML, CSS и JavaScript, без конструктора, фреймворков и внешних библиотек. Никакой сборки не нужно. Счётчиков, рекламы и запросов на чужие сайты нет.

Что нового во второй версии
  Калькулятор: цель выбирается кнопками, видно, из чего сложилась цифра (обмен в покое, активность, поправка на цель), граммы БЖУ на килограмм веса, ИМТ по шкале ВОЗ с пометкой для 16-17 лет. При смене цели или активности результат пересчитывается сразу. Результат можно скопировать и распечатать.
  Запоминание: если стоит галочка «Запомнить», данные калькулятора лежат в localStorage браузера. Кнопка «Забыть мои данные» их стирает. На главной видна последняя норма.
  Замены: фильтр по группам, сортировка по экономии калорий и по алфавиту, Б/Ж/У из справочника, ссылка вида swaps.html#чипсы сразу открывает поиск.
  Продукты: сортировка по клику на заголовок, группы кнопками, тарелка дня: кладёшь продукты, вписываешь граммы, видишь сумму КБЖУ и долю от своей нормы. Тарелку можно скопировать или распечатать.
  Советы: отметка «уже пробую» и кнопка «Вытянуть случайный совет».
  Ночная тема (кнопка «Ночь» в меню), она же включается сама, если в системе стоит тёмная тема.
  Доступность: видимый фокус с клавиатуры, подписи у всех полей, сортировка столбцов объявляется для экранного диктора, при «уменьшить движение» анимаций нет.
  Скорость: шрифты пересобраны в WOFF2 только с латиницей и кириллицей, было около 335 КБ, стало около 126 КБ. Стили сведены в один файл.
  Мета-теги: canonical, Open Graph с картинкой img/og.png (видна при отправке ссылки в мессенджер), theme-color.

Что сайт хранит в браузере (localStorage)
  profit-calc   данные и результат калькулятора, только если стоит галочка «Запомнить»
  profit-plate  тарелка дня
  profit-tips   отметки «уже пробую»
  profit-theme  тема
Всё стирается кнопкой на странице «О команде». На сервер ничего не уходит.

Как открыть у себя
Распаковать архив и открыть index.html двойным щелчком. Интернет не нужен.

Как обновить сайт на GitHub Pages
Сайт лежит в репозитории ejik-star/profit, ветка main, папка / (root). Достаточно закоммитить изменения в main, через одну-две минуты GitHub Pages сам обновит сайт.
Если выкладывать заново в другой аккаунт:
1. На github.com нажать «New repository», назвать, например, profit, тип Public, создать.
2. «Add file» -> «Upload files», перетащить всё содержимое папки сайта. Папку tests можно не загружать.
3. «Commit changes», потом Settings -> Pages: Source «Deploy from a branch», ветка main, папка / (root), Save.
4. Если имя репозитория не profit, поправить адрес в 404.html (строка с base href) и в мета-тегах.
Файл .nojekyll в папке нужен, чтобы GitHub отдавал файлы как есть, его не удалять.

Что нужно вписать самим
  about.html: контакт команды (почта или Telegram) вместо плашки «контакт команды пока не указан». Место отмечено комментарием «ВПИСАТЬ».
  about.html: фото участников, если решите их ставить. Сейчас вместо фото инициалы (div class="avatar").
  Отметки «бюджетно» в js/data.js (budget: true/false) стоит сверить с ценами в ближайших магазинах.
  Опрос пока без ответов, поэтому никаких цифр опроса на сайте нет. Когда ответы появятся, их можно добавить на страницу «О команде».

Как запустить автотесты
Нужны Node.js и Google Chrome (или Chromium).
  cd tests
  npm install
  node site_test.js
Результат пишется в tests/site_test_result.txt. Если Chrome стоит не в обычном месте, путь задаётся переменной CHROME_PATH. Скриншоты страниц можно получить, задав папку в переменной SHOTS.
Проверяются тест-кейсы этапа 5 (ТК-01...ТК-15), новые функции, ввод на границах, доступность, ширина на ПК и телефоне, ошибки в консоли и отсутствие запросов на чужие сайты.

Шрифты и картинки
  fonts/Unbounded.woff2 и fonts/Manrope.woff2: шрифты Unbounded и Manrope с Google Fonts, лицензия SIL Open Font License 1.1. Файлы урезаны до латиницы, кириллицы и нужных знаков и пересобраны в WOFF2.
  fonts/ProfitMono-Regular.woff2: урезанная версия PT Mono (ParaType, SIL OFL 1.1). У PT Mono в лицензии есть зарезервированные имена, поэтому изменённый файл переименован в Profit Mono, как требует пункт 3 OFL. Копирайт ParaType внутри файла сохранён.
  Тексты лицензий лежат рядом в fonts/OFL_*.txt.
  Рисунки в img/ (чипсы, попкорн, яблоко, бутылка, морковь, тарелка, логотип) нарисованы нами в SVG. Фотографий на сайте нет.
