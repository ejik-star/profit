PROfit, сайт о здоровом питании
Учебный проект ОПД ГУАП, группа 4528: Ярошенко А. (капитан), Костин М. (дизайн и разработка), Колычев А. (структура, тексты и данные, записка и паспорт).

Что внутри
  index.html        главная
  calculator.html   калькулятор КБЖУ (формула Миффлина-Сан Жеора, возраст от 16 лет)
  swaps.html        таблица замен: 27 замен, из них 21 бюджетная, поиск и фильтр «только бюджетные»
  tips.html         13 коротких советов
  products.html     КБЖУ 93 продуктов на 100 г, поиск и фильтр по группе
  about.html        о команде, контакт, ссылка на опрос
  404.html          страница «нет такой страницы» (GitHub Pages показывает её сам)
  css/style.css     все стили, палитра из ТЗ этапа 3
  js/data.js        продукты, замены и советы (данные USDA FoodData Central, SR Legacy)
  js/*.js           меню, калькулятор, таблицы, советы
  img/              логотип, картинка тарелки, иконка для телефона
  tests/            автотесты по тест-кейсам этапа 5

Сайт сделан на чистых HTML, CSS и JavaScript, без конструктора, фреймворков и внешних библиотек. Никакой сборки не нужно. Введённые в калькулятор данные никуда не отправляются, всё считается в браузере.

Как открыть у себя
Распаковать архив и открыть index.html двойным щелчком. Интернет не нужен.

Как выложить на GitHub Pages (бесплатно)
1. Зарегистрироваться на github.com (если аккаунта ещё нет).
2. Нажать «New repository», назвать, например, profit, тип Public, создать.
3. На странице репозитория нажать «Add file» -> «Upload files» и перетащить всё содержимое папки сайта (index.html, css, js, img и остальное). Папку tests можно не загружать.
4. Нажать «Commit changes».
5. Открыть Settings -> Pages. В «Build and deployment» выбрать Source: «Deploy from a branch», ветка main, папка / (root), Save.
6. Через одну-две минуты сверху появится адрес вида https://ИМЯ.github.io/profit/. Открыть его с компьютера и с телефона и пройти тест-кейсы этапа 5.
7. Адрес сайта вписать в буклет, стенд, QR-код и записку.
Файл .nojekyll в папке нужен, чтобы GitHub отдавал файлы как есть, его не удалять.

Что нужно вписать самим
  about.html: контакт команды (почта или Telegram) вместо плашки «контакт команды пока не указан». Место отмечено комментарием «ВПИСАТЬ».
  about.html: фото участников, если решите их ставить. Сейчас вместо фото инициалы (div class="avatar").
  Адрес сайта после публикации: в README, буклете, на стенде, в QR-коде.
  Отметки «бюджетно» в js/data.js (budget: true/false) стоит сверить с ценами в ближайших магазинах.

Как запустить автотесты
Нужны Node.js и Google Chrome (или Chromium).
  cd tests
  npm install
  node site_test.js
Результат пишется в tests/site_test_result.txt. Если Chrome стоит не в обычном месте, путь задаётся переменной CHROME_PATH.

Шрифты и картинки
  fonts/Unbounded.woff и fonts/Manrope.woff: шрифты Unbounded и Manrope с Google Fonts (лицензия SIL Open Font License 1.1, файлы урезаны до латиницы и кириллицы), тексты лицензий рядом в fonts/OFL_*.txt.
  fonts/PTMono-Regular.ttf: PT Mono, ParaType, лицензия SIL OFL 1.1, файл без изменений.
  Рисунки в img/ (чипсы, попкорн, яблоко, бутылка, морковь, логотип) нарисованы нами в SVG. Фотографий на сайте нет.
